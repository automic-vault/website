01 / Secrets

Secrets agents cannot read. Tools still work.

Automic Vault stores credentials so agents and malware cannot pull the raw values from files, shells, or model context. The secret is still available to the tool that needs it, so the normal command keeps working.

Access is narrow by design: a GitHub token belongs to gh, AWS credentials belong to aws, and unrelated processes do not get a convenient retrieve step.

Readable by shells, editors, malware, and any agent with file access.

after $ av inject -- gh release create credential available to gh, not the agent

The tool gets what it needs. The model and other processes do not get the raw value.

02 / Approval gates

Put the prompt at the tool boundary.

Built-in agent permissions are useful, but they live inside the thing you are asking to act. Automic Vault adds gates where commands execute: package publishing, token reveal, cloud mutation, and other sharp edges.

03 / Packages

A package manager for machines agents touch.

Automic Vault is both a command-line package manager and a native Mac app. Use av when you already know the command you want; use the GUI when browsing packages, inspecting details, reviewing updates, or managing a machine at a glance.

Both surfaces run on the same Nucleus package engine for Homebrew, npm, and PyPI packages. Release builds install to /opt and expose stubs in /usr/local/bin, so the terminal and app complement each other instead of drifting into separate worlds.

04 / Working style

Use the same terminal. Make the risky bits explicit.

install a tool sudo av install bun gh aws-cli

Installs under the hardened package root.

check files first av secret-scanner ./

Finds local plaintext credentials before the agent session.

trace an installer av trace https://example.com/install.sh

Summarizes shell installer writes before they touch disk.

run with secrets av inject -- tool command

Gives the tool what it needs without handing raw values to the model.

05 / Fits with your stack

Not a replacement for every security tool.

Automic Vault is the local layer under agent execution. Keep your password manager, cloud vault, and source scanners. Add runtime control on the Mac where agents run commands.

Homebrew

Automic Vault installs familiar packages, but owns the root and reduces package drift.

1Password / HashiCorp Vault

Those manage secrets. Automic Vault controls how local tools receive and use them.

Agent permission settings

Those live inside the agent. Automic Vault gates the tools beneath it.
