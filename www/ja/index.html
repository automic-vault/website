01 · DETECT

侵害されたパッケージが必要なのは、たった 1 つのファイル。あなたはいくつ持っていますか。

2026 年最大級の supply chain 攻撃は、本番環境ではなく開発者のラップトップから始まりました。

次の supply chain 攻撃に噛みつかれる前に、スタック内の シークレット露出を検出します。Automic Vault は、ツールがまだ Mac ローカルにあるうちに、パッケージ由来のトークン、認証情報 ファイル、ヘルパーの漏れ、エージェントが読める設定を可視化します。

02.1 · HARDEN (Secrets)

ディスクから外へ。Keychain の中へ。

1 コマンドで、平文の認証情報をエージェントやマルウェアの手が届かない場所へ移します。

Automic Vault はシークレットを扱うパッケージにパッチを当て、 そのシークレットをマルウェアやエージェントから遠ざけます。 対応済みツールには Keychain-backed のヘルパーパスを残すため、 どのローカルプロセスでも読めるファイルに再利用可能な認証情報を 残さずにコマンドを実行できます。

av harden がキーを Keychain に移してヘルパーを書き換えます

credential_process により aws はキーを受け取り、エージェントやマルウェアには露出しません

Package hardening feed 既知のツール、見える制御。

Automic Vault はヘルパープロトコル、一時ホーム、Keychain-backed トークン、平文 hazard 検出のパッケージルールを巡回します。

gh

GitHub tokens saved in Keychain and injected only for gh commands

 awscli

AWS keys moved from ~/.aws/credentials to credential_process

 curl

netrc and curlrc credentials detected as hazards

 git

plaintext credential-store files flagged before agent runs

 npm

registry tokens mounted through a temporary npm config

02.2 · HARDEN (Immutability)

エージェントはツールを実行できる。書き換えはできない。

封印されたインストール。制御されたアップデート。あなたなしでは何も変わりません。

パッケージを不変にインストールすることで、エージェントが自分自身を 変更するのを止め、さらにエージェントやマルウェアがスタック内の重要な ツールを変更するのも止めます。Automic Vault はツールを封印された root に置き、PATH に制御された av shim を公開します。 エージェントはツールを実行できますが、ツール自体の変更は承認済み アップデート経由になります。

エージェントは自分自身を変更できません

02.3 · HARDEN (.env)

.env を暗号化。何も壊さない。

キーは Keychain に残ります。ワークフローはそのままです。

秘密鍵を AV Keychain に安全に保存したまま、dotenvx 互換の .env ファイル暗号化を行います。av dotenv は dotenvx 互換の encrypted: 値を書き、承認済み shell hook は要求した コマンドに対してだけ復号します。

03 · MONITOR

一度きりのスキャンではなく、継続的な検出。

Homebrew、npm、pip、curl — すべて使い続けてください。異常があれば知らせます。

状況が変わったらすぐ通知します。Homebrew、npm、pip、curl の ワンライナーでのインストールは続けてください。困った状態になれば、 Automic Vault が知らせます。

  • マルチソースパッケージ. Homebrew、npm、PyPI のツールをインストールして堅牢化。curl スタイルのインストーラ tracing も同じ workflow で扱います。
  • Touch ID インストール. ターミナルを離れずに権限付きインストールとアップデートを承認。
  • 自動アップデート. アプリと堅牢化ルールをバックグラウンドで最新に保ちます。
  • GUI 検索と発見. パッケージ、ホームページ、バージョン、hazard、セキュリティノートを閲覧。
  • 通知. 新しい脆弱性や露出したシークレットが現れたら分かります。
