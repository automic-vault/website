Automic Vault

Secrets for tools. Execution under control.

Automic Vault is a local macOS secrets and execution manager for developer
tools. It sits between the process asking and the executable that runs. Long-
lived credentials stay in Keychain, approved executables receive named values
for one run, and risky commands can require human approval.

Execution boundary:
1. A shell, script, or agent requests work.
2. Automic Vault resolves the executable, arguments, working directory, and
   requested secrets.
3. The user approves the secret handoff or sensitive command.
4. The local tool receives the secret for that execution and contacts the
   external service itself.

Tool-scoped secrets:
- av save stores a long-lived value in the Automic Vault Keychain.
- av inject gives named values to one approved executable.
- Native helpers such as AWS credential_process, Kubernetes ExecCredential,
  and registry helpers avoid ambient shell exports.

Execution management:
- av contain gives an agent a synthetic toolchain.
- Host tool requests return to Automic Vault with executable path, arguments,
  current directory, parent process, and requested keys.
- Sensitive commands can require human approval before they run.

Commands:
printf '%s\n' "$GITHUB_TOKEN" | av save GITHUB_TOKEN
av inject +GITHUB_TOKEN /opt/homebrew/bin/gh repo view
av contain codex

Automic Vault uses the local facts available at execution time: binary, path,
arguments, parent process, working directory, and tool-specific credential
protocol. Central vaults can remain the source of truth while Automic Vault
controls the last local credential handoff.

Automic Vault is free Apache-2.0 open-source software for macOS.
