Who builds it

Max Howell created Homebrew in 2009.

Homebrew became the default way many macOS developers install command-line tools. Automic Vault comes from a new operating reality: those tools now run under terminals, editors, automation apps, and AI agents, while their credentials often remain readable in plaintext files.

Credential storage

Plaintext secrets are the problem

Automic Vault moves CLI credentials into the macOS Keychain and supplies them only to an approved executable for one run.

Runtime authority

Execution is the boundary

Automic Vault checks the executable, signed launcher, command, working directory, and requested key before handing over a credential.

Open source

Source stays inspectable

The project is Apache 2.0 software on GitHub, so developers can inspect how local control is implemented.

macOS first

The platform is explicit

Automic Vault targets the macOS developer workstation instead of pretending agent security is only a cloud policy problem.

Project position

A local execution boundary for developer tools.

Automic Vault is a local macOS runtime layer for developer tools. It moves credentials out of plaintext files, supplies them to approved executables for one run, and applies policy based on the signed app that launched each tool.

SecretsRemove plaintext credentials

Keep credentials out of files and model context.

Keep a local record of approved and denied requests.
