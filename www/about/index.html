Who builds it

CLI security is broken. The packaging layer is where we fix it.

I know the layer where developers install their tools. It gives us a practical place to change how those tools keep and use credentials. With Automic Vault, we harden supported tools there, then authorize protected operations when they run. Your terminal, editor, and agent keep using their usual commands.

Project position

What that changes on your Mac.

For GitHub, av harden gh installs our signed, patched CLI and migrates its credentials into Automic Vault custody. Its Authorization Gate can allow issue reads while requiring Approval for writes or token disclosure. Homebrew hardening separately gates package changes and protects its installation against same-user modification. Coverage is per supported Tool; AV does not sandbox every command or make an installed package trustworthy.
