01 · DETECT

Ein kompromittiertes Paket muss nur eine Datei lesen. Wie viele hast du?

Die größten Supply-Chain-Angriffe 2026 begannen nicht in Produktion. Sie begannen auf Entwickler-Laptops.

Erkenne Secret-Exposure in deinem Stack, bevor der nächste Supply-Chain-Angriff zubeißt. Automic Vault zeigt Paket-Tokens, Credential-Dateien, Helper-Leaks und agent-lesbare Konfiguration, solange die Tools noch lokal auf deinem Mac sind.

02.1 · HARDEN (Secrets)

Von der Platte. In den Keychain.

Ein Befehl verschiebt Klartext-Credentials außer Reichweite von Agents und Malware.

Automic Vault patcht Pakete, die mit Secrets arbeiten, damit diese Secrets von Malware und Agents fernbleiben. Unterstützte Tools bekommen einen Keychain-gestützten Helper-Pfad, damit der Befehl laufen kann, ohne wiederverwendbare Credentials in Dateien zu hinterlassen, die jeder lokale Prozess lesen kann.

Automic Vault rotiert durch Paketregeln für Helper-Protokolle, temporäre Homes, Keychain-gestützte Tokens und Klartext-Hazard-Erkennung.

 curl

 git

plaintext credential-store files flagged before agent runs

registry tokens mounted through a temporary npm config

02.2 · HARDEN (Unveränderlichkeit)

Agents dürfen deine Tools ausführen. Nicht umschreiben.

Versiegelte Installationen. Kontrollierte Updates. Ohne dich ändert sich nichts.

Stoppe Agents dabei, sich selbst zu verändern, indem du Pakete unveränderlich installierst, und stoppe Agents oder Malware dabei, wichtige Tools in deinem Stack zu verändern. Automic Vault legt Tools in versiegelte Roots und setzt einen kontrollierten av-Shim auf PATH: Agents können das Tool ausführen, aber Änderungen am Tool selbst laufen über ein genehmigtes Update.

.env verschlüsseln. Nichts kaputtmachen.

03 · MONITOR

Kein Einmal-Scan. Laufende Erkennung.

Homebrew, npm, pip, curl — nutze alles weiter. Wir melden, wenn etwas nicht stimmt.

Werde benachrichtigt, sobald sich die Lage ändert. Installiere weiter mit Homebrew, npm, pip und curl-One-Linern und verlass dich darauf, dass Automic Vault dich wissen lässt, wenn du in Schwierigkeiten bist.

  • Multi-Source-Pakete. Installiere und härte Tools aus Homebrew, npm und PyPI, inklusive curl-Installer-Tracing im selben Workflow.
  • Touch-ID-Installationen. Genehmige privilegierte Installationen und Updates, ohne das Terminal zu verlassen.
  • Auto-Updates. Halte App und Paketregeln im Hintergrund aktuell.
  • GUI-Suche und Discovery. Durchsuche Pakete, Homepages, Versionen, Hazards und Security Notes.
  • Benachrichtigungen. Erfahre, wenn neue Schwachstellen oder offengelegte Secrets erscheinen.
