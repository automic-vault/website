01 · DETECT

一个被攻陷的软件包只需要读一个文件。你有多少个？

2026 年最大的供应链攻击不是从生产环境开始的，而是从开发者笔记本开始的。

在下一次供应链攻击咬到你之前，检测技术栈里的密钥暴露。 Automic Vault 会在工具仍然位于你的 Mac 本地时，暴露软件包 token、凭据文件、helper 泄漏以及代理可读取的配置。

02.1 · HARDEN (Secrets)

离开磁盘。进入 Keychain。

一个命令把明文凭据移到代理和恶意软件够不到的地方。

Automic Vault 会修补处理密钥的软件包，让这些密钥远离恶意软件和代理。 支持的工具会获得 Keychain-backed 的 helper 路径，因此命令可以运行， 而不会把可复用凭据留在任何本地进程都能读取的文件中。

照常安装工具

检测密钥暴露

明文密钥在开源工具中很常见

av harden 将密钥移入 Keychain 并重写 helper

credential_process 让 aws 获得密钥，但不暴露给代理或恶意软件

Package hardening feed 已知工具，可见控制。

Automic Vault 会轮询软件包规则，覆盖 helper 协议、临时 home、Keychain-backed token 和明文 hazard 检测。

gh

GitHub tokens saved in Keychain and injected only for gh commands

 awscli

AWS keys moved from ~/.aws/credentials to credential_process

 curl

netrc and curlrc credentials detected as hazards

 git

plaintext credential-store files flagged before agent runs

 npm

registry tokens mounted through a temporary npm config

02.2 · HARDEN (Immutability)

代理可以运行你的工具。不能重写它们。

封印安装。受控更新。没有你的批准，什么都不会变。

通过不可变安装来阻止代理修改自己，也阻止代理或恶意软件修改技术栈中的 关键工具。Automic Vault 将工具放入封印 root，并在 PATH 上暴露 受控的 av shim：代理可以运行工具，但修改工具本身必须走已批准的更新流程。

代理不能修改自己

02.3 · HARDEN (.env)

加密 .env。不中断任何流程。

密钥留在 Keychain。你的工作流保持不变。

dotenvx 兼容的 .env 文件加密，私钥安全存放在 AV Keychain。 av dotenv 写入 dotenvx 兼容的 encrypted: 值，然后已批准的 shell hook 只为请求它们的命令解密。

03 · MONITOR

不是一次性扫描，而是持续检测。

Homebrew、npm、pip、curl — 继续全部使用。出问题时我们会提醒。

情况一变化就收到通知。继续用 Homebrew、npm、pip 和 curl 一行命令安装； 当你陷入风险时，Automic Vault 会告诉你。

  • 多来源软件包. 安装并加固来自 Homebrew、npm 和 PyPI 的工具，并在同一工作流中追踪 curl 风格安装器。
  • Touch ID 安装. 无需离开终端即可审批特权安装和更新。
  • 自动更新. 在后台保持应用和加固规则最新。
  • GUI 搜索与发现. 浏览软件包、主页、版本、hazard 和安全说明。
  • 通知. 新的漏洞或暴露密钥出现时及时知道。
