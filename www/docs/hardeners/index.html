Hardener reference

Hardeners replace supported insecure credential paths with Tool-specific routes that Automic Vault can identify, authorize, and verify. Check the installed state before changing it:

av hardeners --json
av harden TOOL
av doctor TOOL

Tool-specific hardeners

  • AWS — av harden aws
  • Codex — av harden codex
  • Docker — av harden docker
  • Homebrew — av harden brew
  • GitHub CLI — av harden gh
  • Stripe CLI — av harden stripe
  • sudo — av harden sudo
  • Supabase — av harden supabase
